WARP / AmneziaWG 客户端的运行参数。改动保存后服务会自动重启一次，隧道重建约需 10–20 秒。

连接

决定这次连接怎么走，保存后立即生效。

TUN 接管整屋流量

关闭时只在路由器本机开一个混合代理端口（可用 curl -x 验证通路），局域网完全不受影响。建议第一次先关掉确认引擎能连上，再打开接管整屋。

底层协议
使用 OpenVPN 出口

在 WARP 之上再套一层 VPN Gate 公共节点（mihomo 的 openvpn 出站，仅 IPv4）， 出口国家可控，代价是速度下降。首次连接要 1–3 分钟：节点列表要从 VPN Gate 拉取，再逐个试连。

出口地区

留空按延迟自动挑。选了地区但没连上时，引擎会改用其他地区的节点并在日志里说明。

使用 IPv6 端点

仅在当前网络 IPv6 可用时有意义。

开机自启

DNS 与转发

三项都只在 TUN 开启时生效。

接管局域网 DNS

把 dnsmasq 的上游指向内核解析器，避免 DNS 泄漏与污染。断开时自动还原。

解析走隧道

内核解析器的查询跟随规则经隧道发出（respect-rules）。关闭时内核从 WAN 直查明文上游，被墙域名会拿到污染结果（如 youtube / google 解析到不相干 IP），流量走隧道也无法打开。

LAN 失联自愈

TUN 起来后若 br-lan 载波丢失（真机上出现过一次必须断电才能恢复的情况），连续三次读不到载波就自动重启，不必去拔电源。

失联时动作

拔网线和驱动假死从路由器侧无法区分，介意误重启的选「只记录」。

内核 检测中…

实际使用顺序是 /etc/ace/core/mihomo（下载版）优先，没有才用这里填的路径（留空即 /usr/bin/mihomo）。
系统自带的 mihomo 往往偏旧——ImmortalWrt 24.10 是 v1.19.12，不支持 OpenVPN 出站，也不支持 MASQUE。 点「下载并更新」取官方最新版（源不通时自动换镜像），校验 SHA256 后装到 /etc/ace/core/mihomo，约 20 MB；下载版一旦存在就自动优先生效，不必改上面的路径。

分流数据 检测中…

分流（出国流量走隧道、国内流量直连）依赖 geosite.dat 与 geoip.metadb， 两者缺一不可。缺失时连接前会自动下载，不用手动操作；点「下载并更新」拉取最新版并重启服务使其生效。
版本口径不同：geoip.metadb 显示数据库的构建日期（读自文件内部）；geosite.dat 文件里没有版本字段，显示的是本机下载日期。
分流规则由引擎按「绕过大陆」固定生成，不支持自定义规则——这是有意为之的简化。

连接建立后会自动创建 ace0 接口并把局域网流量导进去，同时在防火墙上添加 ace zone（含 masquerade）。 停止连接时这些都会被移除。
如果打开「接管局域网 DNS」，dnsmasq 的上游会被临时改为 127.0.0.1#7874，断开时按备份原样还原。
